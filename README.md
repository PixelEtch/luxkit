# luxkit

Small, offline camera exposure tools that tell you what to set in manual mode. Plain HTML, CSS and JavaScript: no framework, no build step, no network calls at runtime. Made for Safari on iPhone and hosted as static files on Netlify.

**Unofficial.** Not affiliated with Insta360, Panasonic or Freewell.

## Apps

| App | Path | What it does |
|---|---|---|
| Insta360 Luna Ultra | `site/luna-ultra/` | ISO, shutter and ND filter (including ND/PL and stacked filters) for video, in Standard or I-Log, with step-by-step camera setup |

## Repository layout

```
site/                     Netlify publish directory (only this is deployed)
  index.html              hub: list of apps
  manifest.webmanifest    hub manifest
  sw.js                   one service worker for the whole site (offline)
  icons/                  app icons (generated by tools/make-icons.js)
  shared/
    exposure-core.js      camera-agnostic EV maths, no DOM
    ui.css                shared design tokens and controls
    register-sw.js        registers sw.js (http/https only)
  luna-ultra/
    index.html            the app UI
    camera.js             Luna Ultra specs, presets and rules
    manifest.webmanifest  so the app can be its own Home Screen icon
tests/
  core.test.js            node --test unit tests for the shared maths
  luna-ultra.test.js      node --test tests for the Luna rules
  e2e.spec.js             Playwright (WebKit): every input combination, offline
reference/                original single-file version (not deployed)
tools/make-icons.js       regenerates site/icons/*.png (no dependencies)
netlify.toml
```

`exposure-core.js` and `camera.js` load in the browser as plain `<script>` files and in Node via `require` (UMD pattern).

## Run the tests

```bash
npm test                       # unit tests, Node 18+ (no dependencies)
npm install                    # once: installs Playwright (dev only)
npx playwright install webkit  # once: downloads the WebKit browser
npx playwright test            # end-to-end in WebKit at 440×956
```

The end-to-end run serves `site/` with `python3 -m http.server` on port 4173 and saves review screenshots to `test-results/screenshots/`. The Luna page also runs a self-test on load and shows the result in its footer.

To try the site locally: `python3 -m http.server 8080 -d site`, then open http://localhost:8080.

## Deploy (Netlify)

1. Push the repository to GitHub.
2. In Netlify: **Add new site → Import an existing project**, pick the repo.
3. Netlify reads `netlify.toml`: publish directory `site`, no build command. `sw.js` is served with `Cache-Control: no-cache` so phones pick up updates.

### Bump the cache version on every change

The service worker caches every file on the first visit and serves from that cache afterwards. **Whenever any file in `site/` changes, change `CACHE` in `site/sw.js`** (e.g. `luxkit-v1` → `luxkit-v2`), or phones keep showing the old version. If you add a file, also add it to `PRECACHE`.

## Install on iPhone

1. Open the site link in **Safari** once (online), and open each app you want offline.
2. Tap **Share → Add to Home Screen**. The hub and the Luna app can each be added as their own icon.
3. Test it: turn on **Airplane Mode** and open the icon. It should load and calculate normally.

## Exposure method

`EV100 = log2(N² / t) − log2(ISO / 100)`. Light reaching the sensor = scene EV − ND stops (stacked filters add).

1. **Ideal shutter** from the 180° rule: 24 fps → 1/50 (1/48 also fine), 30 → 1/60, 60 → 1/120, 120 → 1/240 (or 1/250), 240 → 1/480 (or 1/500).
2. **Solve ISO** for correct exposure at the ideal shutter.
3. **ISO in range** (±⅙ stop tolerance): keep the ideal shutter and round ISO to the nearest ⅓-stop value. The shutter never moves.
4. **Too bright:** ISO stays at its minimum and the shutter speeds up, capped at 1/8000.
5. **Too dark:** the shutter opens to 1/fps first, then ISO rises, capped at 6400 with an underexposure warning.
6. **Residual error** = log2(ISO used ÷ ISO needed). Within ±0.34 stops is "about right".
7. **Best filter:** chosen from every single filter and every pair of different plain NDs. Standard picks the lowest valid ISO; I-Log picks the ISO closest to 400. Equal-strength ties prefer a single filter, then plain ND over ND/PL. If you have an ND/PL on, the suggestion stays ND/PL.

**I-Log rules.** ISO 400 is treated as the minimum (the native ISO), exposure rounds towards brighter, and any real underexposure is flagged. CineD's lab test found I-Log shadows break up about 1 stop under while highlights hold better.

**Noise warning.** Above ISO 800 at 24/30 fps, or above ISO 400 at 60 fps and up, based on Cinema Tools' noise test.

**Scene brightness.** Either a preset (very bright sun EV 16, sunny 15, normal daylight 14, cloudy 12, shade 11, golden hour 10, indoor 7, night 4) or a **measured EV** typed in from a light-meter app. Use EV at ISO 100: Lightprint's big EV number is already on this scale, which was checked against two readings.

### Not verified (labelled as such in the app)

- The camera's exact ISO and shutter step values. The app rounds to common ⅓-stop values.
- Whether I-Log is available in Slow Motion mode.
- The lowest ISO allowed in I-Log. The app uses 400 as its floor.
- Whether stacking two filters darkens the corners on the 20mm lens.
- How closely the Luna's real exposure matches f/1.8 maths. Compare against the camera's Auto mode in the same light; if it is consistently off, add a correction.
- White-balance Kelvin values per preset are general starting points, not camera-specific.

## Add a new camera app

1. Create `site/<camera>/` with `index.html`, `camera.js` and `manifest.webmanifest` (copy `luna-ultra/` as a start).
2. In `camera.js`, put only that camera's specs, presets and rules. Reuse `shared/exposure-core.js` for the maths (`solveExposure`, `recommendNd`).
3. Add its files to `PRECACHE` in `site/sw.js` and bump `CACHE`.
4. Add a row to the list in `site/index.html`.
5. Add `tests/<camera>.test.js`, and extend `tests/e2e.spec.js`.

## Design

A "printed light meter" look: warm paper and ink with signal orange, square keypad controls, monospace labels. Light by default, warm black in dark mode (follows the iPhone setting). System fonts only, no animations, touch targets at least 44 px, no horizontal scroll at 375 px.
